# Copper City Makerspace

Copper City Makerspace is a community-driven website where people can learn new skills, use shared tools, and connect with other makers. The website provides information about community screenings, workshops, and collaborations.

## Pages Included

- index.html: Home page with an overview of Copper City Makerspace.
- **screenings.html: Information about community screenings and discussions.
- workshops.html: Information about workshops and tools.
- collaborations.html: Information about community partnerships and ways to get involved.

## Stylesheet

All pages use the same `styles.css` file. The website uses a mobile-first design, with a single-column layout on smaller screens and a three-column card layout on larger screens.
